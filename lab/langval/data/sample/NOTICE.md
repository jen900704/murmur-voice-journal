# Sample data notice

`goemotions_train_first200.tsv` holds the first 200 lines of `goemotions/data/train.tsv`, and
`emotions.txt` is a copy of `goemotions/data/emotions.txt`, both from
`google-research/google-research` at commit `ee4298226f21649f45c0d0427f7c0f3f682d2a20`.

GoEmotions: Demszky, D., Movshovitz-Attias, D., Ko, J., Cowen, A., Nemade, G., & Ravi, S. (2020).
GoEmotions: A Dataset of Fine-Grained Emotions. ACL 2020. Copyright Google LLC. Licensed under the
Apache License, Version 2.0 (https://www.apache.org/licenses/LICENSE-2.0). The lines are unchanged.

The sample is here so that the tests run without a network. It is far too small for any result.
The comments are public Reddit comments and some contain rude language.
