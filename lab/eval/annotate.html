Murmur evaluation: human annotation

This page scores replies from a run of the evaluation harness with the same rubrics the LLM judges use. Open a transcripts.jsonl file from lab/eval/runs/<run>/. The file is read inside this browser tab. Nothing is uploaded and the page has no network access.

All conversations are scripted test cases written for testing. They contain wording about self-harm and abuse. Take breaks when you need them.

Keys

0 1 2score the highlighted item and move to the next one
ndoes not apply (only where the item allows it)
↑ ↓ or k jmove between items
← → or [ ]previous or next reply
ujump to the next reply with unscored items
sdownload the labels as JSONL

Labels are also kept in this browser's local storage for this run and rater id, so a reload does not lose them. They stay on this device until you download the file.
