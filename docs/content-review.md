# 內容審閱清單

這份檔案由 `tools/export-content.mjs` 從程式碼產生，請不要直接修改；要改內容請改 `js/lenses.js` 或 `js/bedtime.js`，再重新執行一次。

審閱時可以看：問題是否忠於該取向（Corey 的章節標在標題旁）、是否適合一個人自己做、有沒有責怪或病理化的語氣、在台灣讀起來是否自然。

## 換個角度看看（14 個取向）

### 精神分析取向（Corey 第 4 章）

- [ ] **核心想法：** 現在的反應，常常帶著過去關係的影子。我們心裡會有互相拉扯的願望和擔心，也會用各種方式保護自己，不去碰太痛的感覺。
- [ ] **第 1 題：** 這種感覺熟悉嗎？以前大概什麼時候也有過？寫個大概就好。如果想到的事很痛，先停在這裡，改天或有人陪著時再看。
  - 為什麼這樣問：這個取向會注意，現在的反應是不是在重複某個過去的模式。
- [ ] **第 2 題：** 在這件事裡，一部分的你想要什麼？另一部分的你又在擔心什麼？
  - 為什麼這樣問：它認為內心常同時有想靠近和想保護自己的力量。
- [ ] **第 3 題：** 這種感覺出現時，你通常怎麼讓自己好過一點？例如轉移注意、變得很理性、怪自己或怪別人。
  - 為什麼這樣問：這些保護方式（防衛）不是壞事，它們曾經幫過你，但有時也讓人看不清楚。
- [ ] **看見的（摘要）：** 關於這種感覺以前什麼時候有過，你寫到：「{1}」。心裡想要的和擔心的：「{2}」。它出現時，你讓自己好過一點的方式：「{3}」。這個取向會好奇：這個保護方式以前幫過你什麼，現在是不是還需要用同樣的方式。
- [ ] **小實驗：** 這週，在這個模式出現的那一刻，只是把它記下來（時間、在誰身邊、你做了什麼），先不急著改變。
- [ ] **可能忽略的：** 比較少直接處理眼前能做的事和環境因素。真正的精神分析工作需要長期的治療關係，這裡只借用它的提問方式。
- 關鍵概念：潛意識、防衛機制、重複的關係模式

### 阿德勒學派（Corey 第 5 章）

不提供給這些主題：失落或悲傷

- [ ] **核心想法：** 行為背後有目標，人最深的需要之一是歸屬與貢獻。我們會帶著一套自己的「私人邏輯」看世界，而鼓勵比批評更能帶來改變。
- [ ] **第 1 題：** 如果這個困擾明天就不見了，你的生活會有什麼不同？你會開始做什麼？
  - 為什麼這樣問：阿德勒學派用這個問題看見你想要的生活，以及在這個困擾底下，你真正想靠近的是什麼。
- [ ] **第 2 題：** 在這件事裡，你心裡有沒有一句「我必須……才……」？例如「我必須做到最好，才會被接納」。
  - 為什麼這樣問：阿德勒把這種句子叫做私人邏輯：很少被說出口，卻影響很多選擇。
- [ ] **第 3 題：** 有沒有一件小事，你可以「彷彿」已經是不被這個困擾綁住的自己，去做做看？
  - 為什麼這樣問：「彷彿」練習讓人先在行動上試穿新的自己，不用等到感覺準備好。
- [ ] **看見的（摘要）：** 如果這個困擾不見了，你想像的生活是：「{1}」。你心裡的那句話：「{2}」。阿德勒學派把這類句子叫做私人邏輯，也會問：在這件事底下，你想要的是不是歸屬、被看重、能有所貢獻？如果是環境或別人讓你受傷，那不代表是你哪裡做錯了。
- [ ] **小實驗：** 你想到的小事：「{3}」。選一天，彷彿你已經是那個自己，去做做看。結束後記下別人的反應，和你自己的感覺。
- [ ] **可能忽略的：** 比較少處理身體、創傷和環境的壓力。太強調個人選擇時，可能忽略你無法掌控的部分。
- 關鍵概念：私人邏輯、社會興趣、鼓勵、彷彿技術

### 存在主義取向（Corey 第 6 章）

不提供給這些主題：失落或悲傷

- [ ] **核心想法：** 焦慮是活著的一部分，不只是症狀。即使處境有限，我們仍然在選擇自己要如何回應，而意義常常藏在我們在乎的事情裡。
- [ ] **第 1 題：** 這個煩惱透露了你在乎什麼？如果你一點都不在乎，它還會困擾你嗎？
  - 為什麼這樣問：存在主義取向常從困擾裡找出背後的價值。
- [ ] **第 2 題：** 在這個處境裡，哪些是你沒辦法選的？（有些人會說那是命或緣分，用你習慣的說法就好。）哪些即使很小，仍然是你可以選的？
  - 為什麼這樣問：Yalom 和 May 都談自由與責任：這個取向承認限制，也提醒我們仍有回應的自由。
- [ ] **第 3 題：** 如果朝你真正在乎的方向走一小步，那一步會是什麼？
  - 為什麼這樣問：意義不只用想的，也是在選擇和行動裡活出來的。
- [ ] **看見的（摘要）：** 關於這個煩惱透露你在乎什麼，你寫到：「{1}」。沒辦法選的和還能選的，你是這樣分的：「{2}」。存在主義取向會說：焦慮也可能是在提醒你，這件事對你很重要。
- [ ] **小實驗：** 你想走的一小步：「{3}」。這週試試看，做完後問自己：這一步有沒有比較像我想成為的人？
- [ ] **可能忽略的：** 比較抽象，需要具體技巧的人可能覺得不夠實際。不適合在急性危機或很深的失落中自己使用。
- 關鍵概念：自由與責任、意義、真誠、存在焦慮

### 個人中心取向（Corey 第 7 章）

- [ ] **核心想法：** 每個人都有往成長方向走的力量。當一個人被真誠、準確、不評價地理解時，他通常最知道自己需要什麼。
- [ ] **第 1 題：** 用幾個詞說說你現在的感受，不用合理，也不用解釋。
  - 為什麼這樣問：這個取向從你的經驗出發，不從別人的標準出發。
- [ ] **第 2 題：** 這些感受裡，哪一個是你最少讓別人看見的？
  - 為什麼這樣問：它在意的是你內在經驗和你表現出來的樣子之間的距離。
- [ ] **第 3 題：** 如果有一個真正懂你、不評價你的人在旁邊，你希望他明白你什麼？你現在需要什麼？
  - 為什麼這樣問：Rogers 認為，被真誠、不帶條件地接納、準確地理解，是改變開始的地方。
- [ ] **看見的（摘要）：** 你現在的感受：「{1}」。最少讓別人看見的：「{2}」。你希望被明白的：「{3}」。這個取向相信，你自己最知道方向在哪裡。
- [ ] **小實驗：** 如果身邊有讓你安心的人，可以只說一句「我最近其實有點……」，也可以先說「你聽我講就好」。現在沒有這樣的人，就錄一段話給自己聽，也算數。
- [ ] **可能忽略的：** 提供的方向和技巧較少，需要結構或具體方法時可能不夠。也要誠實說：這只是軟體，給不了真正的關係，而這個取向認為關係本身才是療癒的核心。
- 關鍵概念：同理、無條件正向關懷、真誠一致、實現傾向

### 完形取向（Corey 第 8 章）

不提供給這些主題：失落或悲傷

- [ ] **核心想法：** 改變從此時此刻的覺察開始。注意你身體正在做什麼、你正在怎麼說話，比解釋「為什麼」更能讓人接觸到自己。
- [ ] **第 1 題：** 先停一下。想到這件事時，你身體哪裡最有感覺？是什麼樣的感覺？
  - 為什麼這樣問：完形取向從當下、從身體開始，而不是從分析開始。
- [ ] **第 2 題：** 寫一句關於這件事的「我必須……」或「我不得不……」。
  - 為什麼這樣問：我們說話的方式，常常反映我們怎麼看待自己的處境。
- [ ] **第 3 題：** 把它讀成「我選擇……」，讀起來有什麼不同？照實寫就好，也可以寫「不是我選的」。
  - 為什麼這樣問：換成「我選擇」能讓人看見哪些部分是自己的，哪些其實不是。如果這件事是別人加在你身上的，它就不是你的選擇；也可能是「這是我的責任，我願意扛」，或「我不想，但放不下」。兩種答案都有意義。
- [ ] **看見的（摘要）：** 想到這件事時，你身體的感覺是：「{1}」。你寫下「{2}」，改成「我選擇」之後，你注意到：「{3}」。完形取向在意的不是答案，而是你此刻更清楚地接觸到自己。
- [ ] **小實驗：** 這週每天一次，停下來問自己：「我現在正在做什麼？身體有什麼感覺？」只要注意，不用改變。
- [ ] **可能忽略的：** 比較少處理長期模式和環境因素。更深入的完形練習（例如空椅法）需要在諮商中有人陪著做，不適合自己一個人做。
- 關鍵概念：此時此刻、覺察、「我」的語言、接觸

### 行為取向（Corey 第 9 章）

不提供給這些主題：失落或悲傷

- [ ] **核心想法：** 行為是在情境中被學會、被維持的。看清楚「之前發生什麼、做了什麼、之後發生什麼」，就能設計小而具體的改變，並且用結果來檢驗。
- [ ] **第 1 題：** 最近一次這個困擾出現時，前面發生了什麼？（時間、地點、和誰、在做什麼）
  - 為什麼這樣問：行為取向先看觸發的情境（A，前因）。
- [ ] **第 2 題：** 那時你做了什麼？做完之後，短時間內發生了什麼？你感覺怎樣？
  - 為什麼這樣問：行為（B）和它帶來的結果（C）會決定這個行為會不會一再出現。
- [ ] **第 3 題：** 下次遇到同樣的情境，有沒有一個小到幾乎不可能失敗的不同做法？
  - 為什麼這樣問：改變從小而具體、可以觀察的步驟開始。
- [ ] **看見的（摘要）：** 那次之前發生的事：「{1}」。你做了什麼、之後怎麼樣：「{2}」。短期讓人好過的做法，有時長期反而讓困擾留下來。你想試的新做法：「{3}」。
- [ ] **小實驗：** 幫這個新做法（「{3}」）在行事曆上排一個時間。做之前和做之後各用 0 到 10 記一下心情，一週後比較看看。
- [ ] **可能忽略的：** 比較少探索意義和情緒的內在經驗。比較嚴重的焦慮或創傷（例如需要逐步暴露時）可以和心理師或醫師一起規劃，不要自己硬撐。
- 關鍵概念：前因、行為、後果（ABC）、增強、行為實驗、活動安排

### 正念與接納取向（Corey 第 9 章）

- [ ] **核心想法：** 和難受的想法、感受對抗，常常讓它們更大。練習不帶評價地注意它們，和它們保持一點距離，然後仍然朝自己在乎的方向前進。這裡的正念不是正向思考，也不需要任何宗教信仰。
- [ ] **第 1 題：** 花三個呼吸的時間，注意現在的感受，不去改變它。然後寫下：這個困擾最常對你說的一句話是什麼？
  - 為什麼這樣問：正念從不評價地注意開始。
- [ ] **第 2 題：** 把那句話讀成：「我注意到我有一個想法：……」。這樣看它，你和它的距離有沒有變化？
  - 為什麼這樣問：接納與承諾取向（ACT，Hayes）把這叫做認知脫鉤：想法還在，但你不一定要照它說的做。
- [ ] **第 3 題：** 就算這個想法和感受還在，今天你仍然想朝什麼重要的方向做一點點？
  - 為什麼這樣問：接納不是放棄，而是把力氣留給你在乎的事。
- [ ] **看見的（摘要）：** 這個困擾最常說的話：「{1}」。把它看成「一個想法」時，你注意到：「{2}」。即使它還在，你仍想朝這個方向做一點點：「{3}」。
- [ ] **小實驗：** 這週每次那句話出現，就在心裡加上「我注意到我有一個想法：……」，再朝你寫的方向（「{3}」）做一件小事。
- [ ] **可能忽略的：** 接納不等於忍受不合理或不安全的處境。當問題出在環境或關係裡時，只改變自己和想法的關係是不夠的。
- 關鍵概念：正念、接納、認知脫鉤、價值導向的行動

### 理情行為取向（REBT）（Corey 第 10 章）

不提供給這些主題：失落或悲傷

- [ ] **核心想法：** 讓我們困擾的，常常不只是事件本身，而是我們對事件的信念，特別是那些絕對的「應該」和「必須」。
- [ ] **第 1 題：** 發生了什麼事？只寫事實，像攝影機拍到的那樣。（A，觸發事件）
  - 為什麼這樣問：這是 Ellis 的 ABC 模式：REBT 先把事件和我們對事件的解讀分開。
- [ ] **第 2 題：** 關於這件事，你心裡有沒有一個「應該」或「必須」？例如「他應該要……」「我必須……」。（B，信念）
  - 為什麼這樣問：它認為絕對化的要求，常讓合理的失望變成難以承受的痛苦。
- [ ] **第 3 題：** 帶著這個信念，你的感受和反應是什麼？（C，結果）
  - 為什麼這樣問：REBT 認為感受主要來自 B，而不只是 A。
- [ ] **第 4 題：** 只看「一定要、不然就完了」那部分。改成「我很希望……，做不到也不代表我很糟」，感受有什麼不同？（D 駁斥，E 新的效果）
  - 為什麼這樣問：有些「應該」是你真心看重的責任，不用拿掉。這是溫和版本的駁斥：不是否認你想要的，而是放下「一定要」。Ellis 把駁斥之後出現的新感受和新想法叫做 E（效果）。
- [ ] **看見的（摘要）：** 事件（A）：「{1}」。你帶著的信念（B）：「{2}」。帶來的感受和反應（C）：「{3}」。把「一定要」換成「很希望」之後，你注意到：「{4}」。
- [ ] **小實驗：** 這週每次發現自己說「應該」或「必須」，就試著在心裡改成「我很希望……」，看看感受有沒有不同。
- [ ] **可能忽略的：** 有時太直接。有些「應該」反映的是真實的不公平，問題不只在想法；這時更需要的是改變處境或找到支持。
- 關鍵概念：ABC 模式、非理性信念、偏好與要求、駁斥

### 認知取向（Corey 第 10 章）

不提供給這些主題：失落或悲傷

- [ ] **核心想法：** 我們的感受深受自動冒出來的想法影響。把想法當成可以檢驗的假設，而不是事實，常能找到更平衡的看法。
- [ ] **第 1 題：** 這件事發生時，你腦中第一個冒出來的想法是什麼？
  - 為什麼這樣問：Beck 把這種想法叫做「自動化思考」，認知取向從抓住它開始。
- [ ] **第 2 題：** 有什麼證據支持這個想法？又有什麼證據不太符合它？
  - 為什麼這樣問：把想法當成假設，看看兩邊的證據。
- [ ] **第 3 題：** 如果是你在乎的人（朋友、家人、學弟妹都可以）遇到一樣的事、有一樣的想法，你會對他說什麼？
  - 為什麼這樣問：我們對朋友通常比對自己公平，這能幫你找到更平衡的看法。
- [ ] **看見的（摘要）：** 自動冒出來的想法：「{1}」。你列出的證據：「{2}」。你會對在乎的人說的話：「{3}」。這句話也許也適用在你自己身上，可以當成一個比較平衡的看法。
- [ ] **小實驗：** 準備三句可以對自己說的話：事前（「我知道這會有點難，我可以一步一步來」）、當下、事後各一句。這是 Meichenbaum 的因應自我對話。
- [ ] **可能忽略的：** 不是所有的難受都來自認知扭曲（Beck 指的是想法偏離事實的習慣，例如非黑即白）。有時你的想法是準確的，問題在處境本身；這時要做的不是改想法，而是處理處境。
- 關鍵概念：自動化思考、認知扭曲、證據檢驗、平衡的想法、因應自我對話

### 現實取向與選擇理論（Corey 第 11 章）

不提供給這些主題：失落或悲傷

- [ ] **核心想法：** 我們都在努力滿足生存、愛與歸屬、權力（成就感）、自由和樂趣這五種需求。與其停在過去，不如看清楚：我想要什麼、我正在做什麼、這有沒有用、接下來的計畫是什麼。
- [ ] **第 1 題：** 在這件事裡，你真正想要的是什麼？（W，想要）
  - 為什麼這樣問：現實取向從釐清你想要什麼開始。這四題是 Wubbolding 依 Glasser 的選擇理論整理出的 WDEP。
- [ ] **第 2 題：** 你現在實際上在做什麼？請寫具體的行為，不是感覺。（D，行動）
  - 為什麼這樣問：它把焦點放在你能掌握的行動上。
- [ ] **第 3 題：** 你現在做的事，有讓你更接近想要的嗎？（E，評估）
  - 為什麼這樣問：自我評估是這個取向的核心：由你判斷，不是由別人評價。
